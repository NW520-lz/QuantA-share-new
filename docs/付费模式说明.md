# QuantA Share 付费模式（成本导向）

## 1. 成本假设
- 数据与基础算力成本：约 `39 元/用户/月`
- 目标毛利：`60%`
- 价格下限公式：`价格 >= 成本 / (1 - 毛利率)`，即 `>= 97.5 元/月`

## 2. 套餐建议
- `Starter 月付`：`99 元/30天`
- `Pro 月付`：`199 元/30天`
- `Pro 年付`：`1990 元/365天`

## 3. 权益差异
- 日扫描额度
- AI 调用额度
- 回测标的数量

## 4. 登录与支付联动
- 登录成功后，后端返回 `is_subscribed / plan_code / trial_ends_at`
- 已订阅（或试用中）进入看板
- 未订阅跳转付费中心选择套餐

## 5. 试用策略
- 新用户自动 `7 天试用`
- 到期后需要购买套餐继续使用核心功能
